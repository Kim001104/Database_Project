# 서울시 부동산 데이터 분석 웹 응용

## 프로젝트 개요

본 프로젝트는 서울시 부동산 임대차 계약 공공 데이터를 기반으로 자치구 → 동 → 건물 유형 → 면적(평수) 조건에 따라
월세 및 보증금 데이터를 단계적으로 분석할 수 있는 데이터베이스 중심 웹 응용이다.

## 주요 기능

1. 자치구별 평균 월세 시각화

2. 자치구, 동, 건물 유형별 상세 분석

3. 면적(평수) 범위 기반 계약 조회

4. 평균 월세 / 평균 보증금 / 계약 수 집계

5. 계약 상세 데이터 테이블 제공

## 데이터베이스

**DBMS**: SQLite

데이터 **출처**: 서울시 부동산 임대차 계약 공공 데이터 (JSON)

주요 **테이블**: real_estate


## 개발 환경

Language: Python

Framework: Flask

Frontend: HTML / CSS / JavaScript

Visualization: Chart.js

## 요약

공공 데이터를 관계형 데이터베이스로 변환하여 SQL 집계 및 조건 질의 기반 분석 서비스
**데이터베이스 설계 중심**의 웹 응용 프로젝트
